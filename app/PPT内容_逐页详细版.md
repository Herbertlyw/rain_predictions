## 幻灯片 4：为什么选择超图？⭐

### 标题
超图vs传统方法：更强的表达能力

### 三栏对比

#### 左栏：传统CNN
```
┌──────────────┐
│ ■ ■ ■ ■ ■    │
│ ■ ■ ■ ■ ■    │  → 只能建模局部邻域
│ ■ ■ ■ ■ ■    │     二元关系
│ ■ ■ ■ ■ ■    │
└──────────────┘
    ❌ 表达能力有限
```

#### 中栏：标准图神经网络
```
    A―B
    │╲│
    C―D
    
一条边连接2个节点
❌ 难以表达高阶关系
```

#### 右栏：超图（我们的方法）✅
```
    A   B   C
     ╲  │  ╱
      ╲ │ ╱
       ╲│╱
        ●  ← 超边
       ╱│╲
      ╱ │ ╲
     ╱  │  ╲
    D   E   F

一条超边连接多个节点
✅ 自然建模局部邻域
✅ 捕获高阶依赖关系
```

### 底部总结
**超图的优势**：一条超边可以连接任意数量的节点，天然适合建模卷积感受野！
