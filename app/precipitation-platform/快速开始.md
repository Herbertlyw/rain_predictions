# 快速开始指南

## 方式一：一键启动（推荐）

### macOS / Linux

```bash
# 进入项目目录
cd precipitation-platform

# 运行启动脚本
./start-all.sh
```

### Windows

```cmd
# 进入项目目录
cd precipitation-platform

# 运行启动脚本
start-all.bat
```

脚本会自动：
1. 检查环境（Python、Java、Maven）
2. 创建Python虚拟环境
3. 安装依赖
4. 启动三个服务

## 方式二：手动启动

### 1. 启动AI服务

**终端1**：
```bash
cd ai-service
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
python flask_app.py
```

### 2. 启动Spring Boot后端

**终端2**：
```bash
cd backend
mvn spring-boot:run
```

### 3. 启动前端

**终端3**：
```bash
cd frontend
python3 -m http.server 3000
# 或使用: npx serve -s . -p 3000
```

## 访问系统

打开浏览器访问：**http://localhost:3000**

## 使用流程

1. **上传NPY文件**
   - 点击或拖拽文件到上传区域
   - 支持多文件上传

2. **配置参数**
   - 输入帧数量：5（默认）
   - 预测帧数量：5（默认）
   - 勾选"生成对比图"

3. **开始预测**
   - 点击"开始预测"按钮
   - 等待处理完成（约10-30秒）

4. **查看结果**
   - 输入图像展示
   - 预测结果展示
   - 对比图展示
   - 性能指标（MSE、SSIM）

5. **下载结果**
   - 点击"下载完整结果"
   - 获取包含所有图像和数据的ZIP文件

## 测试数据

如果没有NPY数据文件，可以使用Python生成测试数据：

```python
import numpy as np

# 生成5个500x500的随机雷达回波数据

    data = np.random.rand(500, 500) * 100  # 模拟降水强度
    np.save(f'test_data_{i}.npy', data)
```

## 常见问题

### Q1: 端口被占用

**解决方案**：修改配置文件中的端口号
- 前端：修改启动命令中的端口
- 后端：修改 `backend/src/main/resources/application.yml` 中的 `server.port`
- AI服务：修改 `ai-service/flask_app.py` 中的 `app.run(port=5000)`

### Q2: Maven构建失败

**解决方案**：
```bash
# 清理并重新构建
cd backend
mvn clean install -U
```

### Q3: Python依赖安装失败

**解决方案**：
```bash
# 使用国内镜像
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q4: 找不到模型文件

**解决方案**：
- 确保 `best_model.pth` 或 `predrnn_v2_best.pth` 在项目根目录
- 或修改 `ai-service/flask_app.py` 中的 `MODEL_PATH` 指向正确路径

## 停止服务

### 使用一键启动脚本

按 `Ctrl+C` 即可停止所有服务

### 手动启动方式

在每个终端中按 `Ctrl+C`
